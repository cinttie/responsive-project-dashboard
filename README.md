# TaskFlow - Responsive Project Dashboard

A responsive project and task management dashboard built with HTML, CSS, and vanilla JavaScript.

## Live Demo

https://cinttie.github.io/responsive-project-dashboard/

## Features

- Create new tasks with categories and priority levels
- Mark tasks as completed or active
- Delete tasks
- Filter tasks by All, Active, and Completed
- Automatically update task statistics
- Save task changes with localStorage
- Responsive mobile-first layout
- Dynamic DOM manipulation and event handling

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM API
- Web Storage API (localStorage)
- Git & GitHub
- GitHub Pages

## What I Built

I built TaskFlow to practice creating an interactive front-end application without relying on a framework.

The dashboard uses JavaScript to dynamically create and modify task elements, respond to user events, calculate task statistics, filter application state, and persist changes between browser sessions using localStorage.

I also designed the interface to adapt across desktop and mobile screen sizes.
